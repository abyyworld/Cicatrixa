Moving to a server

Nothing is built or run here — there is no Docker host yet. When one is up, one command on the box imports every user (their passwords keep working), this GitHub App, every connection and every planned project. Then app.cicatrixa.com moves to the box, the platform deploys the projects, and everyone gets the email they were promised. In this order, on the box in /root/cicatrixa-platform:

# 1. import: see what it would do, then do it
docker exec cx-control python -m app.import_online --dry-run
docker exec cx-control python -m app.import_online
# 2. Cloudflare DNS: move app and * to the box (or the tunnel), remove app from Vercel
# 3. verify, while no customer app runs yet
VERIFY_ALLOW_RESTART=1 ./verify-public.sh
# 4. restart: imported projects start deploying
docker restart cx-control
# 5. email everyone whose projects are deploying
docker exec cx-control python -m app.import_online --notify

Leave out step 5 and nobody hears that deploying opened. The steps around these — the box, platform/.env, Vercel's domain — are in docs/RUNBOOK.md, section “Leaving Vercel”.
