GitHub App

Users can now connect via one-click install. Webhooks are delivered to .

If the base domain changes, update the app's webhook & callback URLs at . The move to a server carries this App over, so every installation keeps working.

One click creates a GitHub App with the right permissions (contents:write for pushing fixes, metadata, pull_requests, push events) and stores its credentials here, the secret ones encrypted. Create it under the company organization, not a personal account — it's the app every customer will install, and it moves with Cicatrixa to the server.

Moving to a server

Nothing is built or run here — there is no Docker host yet. When one is up, one command on the box imports every user (their passwords keep working), this GitHub App, every connection and every planned project, and the platform deploys them. Then app.cicatrixa.com moves to the box.

docker exec cx-control python -m app.import_online --dry-run
docker exec cx-control python -m app.import_online

The exact order — box, platform/.env, import, DNS, Vercel — is in docs/RUNBOOK.md, section “Leaving Vercel”.
